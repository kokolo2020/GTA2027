# Chit Chat City 0.63.0 - Outbreak rescue missions

- New OUTBREAK POST beside the portal in Paris, Tokyo, New York and Bangkok. Tap START RESCUE for a 4-minute mission.
- Find 3 waving survivors (cartoon zombies stand nearby but never chase). Each survivor tells you one step of the valve order.
- Turn the red, blue and green valves in that order. A wrong order resets them and costs 20 seconds; time running out pulls you home.
- Rewards: $4,000 + 400 XP once a day per world, $15,000 the first time you seal a world, and $50,000 + 2,500 XP when all four worlds are sealed.
- World picker shows "sealed" for each world you have saved.

Validation (Mac): parse check, all-world screenshot test with a scripted outbreak run in each world (start, rescue, wrong order, seal, timeout), import, smoke, save restore. Touch controls not yet checked on the Fold5.
