# Harbor City 0.56.1 - Sun Dome and hourly challenges

- New Sun Dome: a giant futuristic glass dome over Harbor Commons (neon lattice, golden sun core, pylons, glowing floor). Everyone now spawns inside it.
- Challenge Core: a hologram tower with a ring of seats to hang out and chat, and the Hourly Challenge terminal.
- Hourly Challenge: a new hard puzzle every hour, same for everyone (Neon Grid 5x5, Slide 15, Code Breaker). $900 and 150 XP once an hour; double for beating par on Grid and Code Breaker.
- Stream Mode now joins online like a normal start, so players can see the streamer.

Validation (Mac): hourly puzzle self-test passed for 9 sample hours; screenshots checked. Phone FPS inside the dome is unverified.
