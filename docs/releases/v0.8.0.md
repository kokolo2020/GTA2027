# Harbor City 0.8.0 — The North Update

Explore the North Highway, Industrial Quarter, Maple Suburbs, Harbor Airfield and Summit Pass. Adds eight discoveries, two time trials, original Blender scenery and a North Explorer mission.

Single-player, offline Android prototype. Install the APK over your existing Harbor City installation; do not uninstall if you want to retain money, cars, upgrades and discoveries.

Requires Android 7 or later, ARM64 and OpenGL ES 3. Debug-signed test build using the existing certificate. Desktop regression passed; Fold5 performance and this version's update-over-install still need testing.
