# Harbor City 0.53.2: restore original characters

Rolls back the 0.53.0 and 0.53.1 character redesigns. The player, city NPCs and online avatars use the original 0.52.1 character appearance, wardrobe and animation behavior again. Removes the new Male / Female / Classic selector. The rest of the city and streamer features remain as before the character trial.

Install this update over your existing app. Money, cars, homes, missions, wardrobe purchases and other saved progress are preserved. Same Android package and signing identity; a higher Android version code allows installation over 0.53.1. No uninstall or save migration needed.

Validation: desktop import, full smoke test and rendered gameplay screenshot; Android and Web exports and APK integrity/package/version/signing checks. Not tested on a phone.
