# Harbor City 0.54.1: passport freeze fix

Fixes the World Biosphere passport: after you closed it, the joystick ignored your finger and the character could not move. Cause: the passport's redrawn buttons stayed in the game's touch-button list after they were deleted, so every later screen touch hit an error before the joystick could start. The passport now removes them properly, the touch handler skips deleted buttons, and the joystick is reset when the passport opens and closes.

Install this update over your existing app; do not uninstall. Same signing certificate; progress is kept. Debug-signed test build.

Validation: code change only in the passport open/close; run through the desktop smoke test. Not yet checked on a phone.
