# Chit Chat City 0.60.0 - World portal: Paris, Tokyo, New York, Bangkok

- Chit Chat City is now a small platform of worlds. The WORLD PORTAL (button bottom right, or the gate on the Ridge lawn) opens a picker with four real-city worlds built from OpenStreetMap.
- New worlds: Tokyo (Shibuya Crossing with giant screens, Hachiko statue), New York (Times Square billboards and red steps), Bangkok (Wat Arun). Paris is unchanged.
- Every world has a landmark, a café, 4 daily quests (+$300 each, bonus for all four) and a return portal. Inside a world the button reads PORTAL HOME. The picker shows today's quest progress per world.
- Menu > GO > World portal teleports you to the gate. Map credit: (c) OpenStreetMap contributors (ODbL).

Validation (Mac): import, smoke, screenshot test of all four worlds, desktop save restore. Not yet checked on the Fold5.
