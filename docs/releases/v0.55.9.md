# Harbor City 0.55.9 - Africa savanna reserve

- The Africa dome is rebuilt as an open savanna. No pens: giraffes, zebras, flamingos, elephants, lions, rhinos and meerkats each roam a big organic habitat and rest between moves.
- Visitors walk only on a raised boardwalk: ramp from the door, a central deck, a pier and two arms that run right beside the animals. The ground is closed to visitors.
- Savanna detail: grass tufts, wildflowers, acacias, termite-mound bush islands, a granite kopje, dry creek bed, wallow logs, rubbing posts, a stream, a giant baobab, glowing lanterns and rim scrub.
- Animals are spotted from 30 m in this dome, and walk to the nearest boardwalk when fed.
- The other six domes are unchanged for now.

Validation (Mac): see release log. No Fold5 was connected, so phone FPS and memory are unverified.

Package com.koko.harborcity, version 0.55.9 / code 105. Install over the existing app to keep progress.
