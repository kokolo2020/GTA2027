# Chit Chat City 0.61.0 - Mystery cases and the mystic sky island

- Each city world (Paris, Tokyo, New York, Bangkok) has a daily mystery: find 3 glowing clues (each riddle answer is one digit), then enter the 3-digit code at the CASE BOARD beside the return portal.
- Solving pays $600 a day. The first solve in a city also pays $1000 and gives a permanent relic (Tower Key, Hachiko Bell, Broadway Star, Arun Lotus).
- 4 relics unlock the Mystic Sky Island (bottom button of the world picker): a floating island with a shrine. First activation +$5000 and +500 XP, then a daily wish +$500.
- The world picker shows clue and relic progress per city.
