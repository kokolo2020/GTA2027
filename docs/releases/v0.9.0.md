# Harbor City 0.9.0 — Online Test

Adds an optional online mode. Tap "Online: OFF" in the top-right HUD row (left of the radio button) to see other online drivers as tinted cars with name tags. Off by default; the game still works fully offline.

First version only: other cars and name tags. No collisions, shared money or chat. Uses a public Supabase Realtime channel, so treat it as a test.

Adds the Android INTERNET permission (auto-granted). Install over your existing app; do not uninstall. Same signing certificate.

Needs two phones online to test. Fold5 performance and the live connection are untested.
