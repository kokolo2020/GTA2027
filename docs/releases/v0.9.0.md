# Harbor City 0.9.0 — Online Preview

Adds an optional experimental Online button. When enabled and connected to the configured Supabase Realtime lobby, other players appear as non-colliding cars or on-foot markers. Online starts off; single-player progression, cars, money and discoveries remain local.

Includes all v0.8 North Update content, radio, pedestrians, tuning, trials and street events.

Install this APK over your existing Harbor City app to retain saves. Android 7+, ARM64, GLES3. This build requests Internet permission for the optional online connection.

Desktop regression covers message handling, peer rendering/state, validation and timeout behavior without connecting to the server. Live two-device online behavior and Fold5 performance have not been verified as part of this release check.

APK SHA256: 89e997cf73654aeb9e912046b4a130ae827068d763833f5e11899bff5425af7c

The local server configuration is intentionally untracked. Only the placeholder example is in Git. The APK contains a public anonymous client key, never a service-role credential.
