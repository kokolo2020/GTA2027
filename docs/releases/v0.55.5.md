# Harbor City 0.55.5 - second level, hub doors, no shortcuts

- Sky galleries: a gentle spiral walkway climbs the wall of Africa, South America, Antarctica, Europe, North America and Oceania to an 8 m lookout (Asia keeps its rain terrace). Each gallery is placed clear of animal pens.
- The central hub now has a gold door frame with a name sign on the entrance walk and on the doorway to every dome.
- Solid rails along both edges of the dome-to-dome path stop cars and hoverboards cutting across the lawns; openings stay at every dome door, hub spoke and the entrance walk.
- An invisible car-only fence around the whole campus keeps cars out (people and hoverboards pass as before).

Validation (Mac, native Web-lite bench): import and full desktop smoke test passed. No Fold5 was connected, so phone FPS and memory are unverified.

Package com.koko.harborcity, version 0.55.5 / code 101. Install over the existing app to keep progress.
