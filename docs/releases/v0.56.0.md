# Harbor City 0.56.0 - Stream Mode

- New auto-play mode for livestreaming on the Mac with Godot (launch arg `--autoplay`, default 3 hours). The player does biodome quests, strolls the boardwalks, rides the sky train and wanders the crowded city, then moves to the next dome.
- Normal play and the Android app are unchanged.
- How to run it: docs/stream/RUN-STREAM-MODE.md

Validation (Mac): sped-up test completed dome, train boarding, ride, alighting and city wander. 3-hour soak and taxi/careers phase not done.
