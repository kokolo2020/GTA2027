# Harbor City 0.55.6 - dome signs, solid hub doors, visitors, guided quests

- Every dome entrance has a large sign board with the dome name (e.g. AFRICA BIODOME), ENTER and FREE ENTRY.
- The central hub wall is now solid. The only ways through are 8 doors (the walk from the city and one per dome), each with a gold frame, name board and open glass leaves.
- The biosphere is no longer empty: 23 visitors stroll the paths into each dome, round the dome-to-dome loop and across the hub.
- Entering a dome starts its next ranger quest. The screen shows an arrow and the distance to the glowing marker (or to the dome door when outside), and each marker has a tall light beam. Standing on a marker runs the task automatically; counting and lantern quests still wait for a feeding show or dusk.

Validation (Mac): import, focused biosphere checks (hub wall blocks, doors open, quest auto-start and guide) and the full desktop smoke test passed. No Fold5 was connected, so phone FPS and memory are unverified.

Package com.koko.harborcity, version 0.55.6 / code 102. Install over the existing app to keep progress.
