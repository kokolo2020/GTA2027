# Harbor City 0.55.3 — Biosphere restyle

The World Biosphere now looks much closer to the original conservatory: thick, saturated coloured gridshell ribs on all seven domes; a ring of leafy trees, flower beds and lanterns inside every dome (cherry blossoms around the Asia rain terrace, snow pines in Antarctica); coloured columns joined by glass rails along the back of each dome; a back-wall waterfall in Europe and North America; and flower hedges, lamp posts and oaks along the entry walk and the seven spokes.

These are visual additions only. Walking, free entry, sealed dome doors, pen safety, quests, animals, passport pages and saved progress are unchanged.

Validation (Mac, native Web-lite bench): import and the full desktop smoke test passed. Asia 206.3 FPS (0.55.2: 201.4), Europe 204.9, Africa 239.4. Peak memory is higher than 0.55.2 on this bench (Asia about 719 MiB versus 631 MiB), so memory on the phone is not verified. No Fold5 was connected; actual phone FPS and coexistence with the YouTube app are unverified.

Package com.koko.harborcity, version 0.55.3 / code 99. Existing signing identity preserved. Install over the existing app to keep progress.
