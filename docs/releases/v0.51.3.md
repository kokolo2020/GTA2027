# Harbor City 0.51.3: join the stream in one step

- **Short link**: viewers can type kokolo2020.github.io/GTA2027/p (or /join) to open the game in the browser. The streamer's PLAY WITH ME card shows it under the QR code.
- **Land next to the streamer**: opening the game from the short link or the QR code goes online straight away (no name box first), saves the starter crate for a little later, and puts you right next to the player who is streaming, with a big welcome ("You're playing with ... say hi!") and a quick how-to-move.
- **Viewer counter**: in streamer mode a big badge shows "🎮 N viewers playing now!" and flashes with a chime when someone joins. The leaders line no longer covers the chapter bar.
- **Faster browser start**: the browser download is 3.6 MB smaller (the browser never showed the bump-detail textures, so they are no longer packed), and there is a new loading screen with a progress bar. The Android app is 0.5 MB smaller too (an unused model is no longer packed).

Install over your existing app; do not uninstall. Same signing certificate; progress is kept. Debug-signed test build.

Desktop smoke test passed (streamer flag, short link pages, landing next to the streamer, welcome banner, crate later, viewer counter). Browser load timed in Safari on the Mac. Joining a live stream from a second device has not been tested yet.
