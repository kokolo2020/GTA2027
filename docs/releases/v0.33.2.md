# Harbor City 0.33.2: looks the same on every device

- **Symbols on iPad and in browsers**: the ● ◆ ▶ ✕ ★ ♥ symbols and the arrows showed as empty boxes in the browser version (for example on iPad). The game now bundles the free Noto Sans Symbols 2 font (SIL Open Font License, see credits.txt), so they show on every device. Thin arrows are now filled ⬆ ➡ ⬇ ⬅ arrows.
- **Level 20 rings**: the rainbow ring is now a fixed rainbow all the way around, so a level 20 player looks the same on every phone. It used to cycle through colours, so two devices showed different colours.
- **Other players' names**: they now sit right above each player, the same size as your own. Before, they floated so high they could go off the top of the screen up close.

Install over your existing app; do not uninstall. Same signing certificate; progress is kept. Debug-signed test build.

Desktop smoke test passed, including a check that every symbol has a font. Not yet tried on the iPad.
