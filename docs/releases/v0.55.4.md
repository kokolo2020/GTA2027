# Harbor City 0.55.4 - Biosphere doors, walls and dome links

- Gold ENTER arch on every dome and a tall gold EXIT arch inside with lights leading to it.
- Visible dome walls: dark plinth plus glass up to the roof, door gap only at the entrance.
- An open ground path (radius 72 m) links each dome to its neighbours, so you no longer return to the hub. Hub spokes keep a 7 m gap where the loop crosses.
- City-style signposts with names and distances outside and inside each dome door.

Walking, free entry, sealed domes, quests, animals, passport pages and saved progress are unchanged.

Validation (Mac, native Web-lite bench): import and full desktop smoke test passed; Asia 194.8 FPS (0.55.2: 201.4). No Fold5 was connected, so phone FPS and memory are unverified.
