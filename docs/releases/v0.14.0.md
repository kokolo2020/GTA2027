# Harbor City 0.14.0 — Airport Line bus

- New public bus (Airport Line) that loops between Harbor Waterfront and Harbor Airfield along the North Highway, in both directions.
- Six stops with signs and shelters: Harbor Waterfront, Downtown, North Gate, Industrial Quarter, Maple Suburbs, Harbor Airfield.
- Walk up to the bus while it waits at a stop and tap BOARD BUS; tap GET OFF at any stop to hop off next to the shelter. The bus is free.
- Until the North Gate opens (3 Bay sites) the bus only runs Waterfront - Downtown - North Gate.
- Buses are local to each device (not shared online). Tokens and job spots still take priority over the BOARD BUS button.
- Includes everything from 0.13 (Marina Heights, shops, levels).

Install over your existing app; do not uninstall. Same signing certificate. Debug-signed test build.
Package: com.koko.harborcity, version 0.14.0 / code 14.
