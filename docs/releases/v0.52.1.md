# Harbor City 0.52.1: cleaner streamer mode

Streamer mode (Menu > Streamer mode) now shows only what a livestream needs.

- **Shown:** the join card (with a small menu button on its corner), joystick, action button, BOARD, RUN, the camera button, quick chat, and the job and chapter step bars while active. Players' name tags and the celebrations stay.
- **Hidden:** quest bar, QUESTS / PLAYERS / CHAT buttons, chat log, minimap, money and online pills, LIVE badge, leaders line, feed, toasts, small QR, screen arrow, achievement banner and the rest of the full HUD. Turning streamer mode off puts everything back exactly where it was.

Install over your existing app; do not uninstall. Same signing certificate; progress is kept. Debug-signed test build.

Desktop smoke test passed. Not yet checked on a phone.
