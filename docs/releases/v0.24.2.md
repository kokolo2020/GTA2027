# Harbor City 0.24.2: Treasure objects and FIND ME on the pavement

- **Treasure hunts name an object to look for**: each round hides the chest next to one of six big objects (giant rubber duck, red beach umbrella, purple hot-air balloon, pirate flag, stack of blue barrels, giant pineapple). The clue says which one: first "Look for a GIANT RUBBER DUCK somewhere around Bay Promenade", then the exact landmark, then the golden beam in the last 90 seconds. The object shows from about 110 m; the chest only within 35 m.
- **FIND ME moves you off the road**: starting FIND ME in the road moves your character to the nearest pavement first, so you hide beside the road, not in the lanes.

Install over your existing app; do not uninstall. Same signing certificate; progress is kept. Debug-signed test build.

Desktop smoke test passed:

- FIND ME moves from the road to the pavement
- all earlier checks

Not yet tested on the Fold5 or with real phones online together.
