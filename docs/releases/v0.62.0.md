# Chit Chat City 0.62.0 - Explore mode

- New Explore mode (Menu > GO > Explore mode): a free camera tour with no player, cars or HUD.
- Left thumb moves, right thumb looks, two fingers zoom, UP/DOWN change height, SPEED slow/medium/fast.
- Jump buttons: City, Paris, Tokyo, New York, Bangkok and the Sky island (once unlocked). EXIT or Back returns to the game.

Validation (Mac): parse check, all-world screenshot test including an Explore run (enter, six jumps, exit, player and HUD restored). Touch controls not yet checked on the Fold5.

Package com.koko.harborcity, version 0.62.0 / code 130.
